# ADR 0002: Вибір стеку тестування (Vitest, StrykerJS, Playwright)

## Status
Прийнято (Accepted)

## Context
Одна з лабораторних вимагає покриття критичної бізнес-логіки юніт-тестами, проведення інтеграційних тестів (з підняттям БД), мутаційного тестування та E2E тестування. Наш проєкт використовує TypeScript, ESM модулі та React на клієнті.

## Decision Drivers
* Нативна підтримка TypeScript та сучасного синтаксису ESM без складних конфігурацій.
* Висока швидкість виконання у середовищі Github Actions.
* Здатність E2E фреймворку симулювати конкурентні дії двох користувачів (наприклад, одночасний репорт рахунку матчу).

## Considered Options

* **Unit / Інтеграційні: Vitest vs Jest**
  * *Vitest (Обрано):* Плюси — використовує `esbuild` для швидкої компіляції, нативно розуміє TypeScript та ESM, спільний конфіг з фронтенд-збирачем. 
  Мінуси — відносно новий інструмент порівняно з Jest.
  * *Jest:* Плюси — Звичність для команди. Мінуси — повільний, вимагає налаштування `ts-jest` для TypeScript, часто конфліктує з ESM імпортами.
* **Мутаційне тестування: StrykerJS vs PIT / mutmut**
  * *StrykerJS (Обрано):* Плюси — єдиний надійний інструмент для екосистеми JavaScript/Node.js, що підтримується завданням.
  * *PIT / mutmut:* Відхилено, оскільки це інструменти для Java та Python відповідно.
* **E2E: Playwright vs Cypress**
  * *Playwright (Обрано):* Плюси — нативно підтримує роботу з кількома контекстами (вкладками/користувачами) одночасно, що критично для тестування турнірних конфліктів. Працює швидше ніж інші альтернативи.
  * *Cypress:* Плюси — зручний UI для дебагу. Мінуси — архітектурно складніше тестувати багатокористувацькі сценарії в одному тесті.

## Decision
Ми обрали **Vitest** для юніт/інтеграційного тестування, **StrykerJS** для мутаційного та **Playwright** для E2E.

## Consequences
* **Позитивні:** Максимально швидкий зворотний зв'язок у CI-пайплайні завдяки Vitest; відсутність проблем з налаштуванням TypeScript середовища для тестів.
* **Негативні:** Команді потрібно вивчити нові технології які раніше ніде не використовувались нами.
