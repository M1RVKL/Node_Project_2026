# ADR 0001: Вибір веб-фреймворку для API (Fastify)

## Status
Прийнято (Accepted)

## Context
Для розробки бекенду платформи турнірів з настільного тенісу потрібен веб-фреймворк на платформі Node.js. Згідно з вимогами подальших лабораторних, система буде піддаватися профілюванню та навантажувальному тестуванню для виявлення "вузьких місць" у бізнес-логіці. 

## Decision Drivers
* Мінімальні використані ресурси фреймворку на обробку HTTP-запитів, щоб профайлер фіксував навантаження саме на бізнес-логіку.
* Можливість гнучкого налаштування Layered Architecture та впровадження Dependency Injection для ізоляції модулів.
* Нативна або швидка інтеграція з TypeScript та засобами валідації.

## Considered Options

* **Fastify**
  * *Плюси:* Найвища продуктивність серед мінімалістичних фреймворків; вбудована швидка серіалізація JSON; не нав'язує жорсткої архітектури, що дозволяє вільно побудувати власну Layered Architecture.
  * *Мінуси:* Менша екосистема готових рішень порівняно з Express; інша парадигма роботи з плагінами замість класичних middlewares.
* **Express.js**
  * *Плюси:* Найбільша екосистема, знайомий усім членам команди, величезна кількість документації.
  * *Мінуси:* Застаріла архітектура обробки асинхронних запитів; низька базова продуктивність, що може спотворити результати профілювання (боттлнеком стане сам Express, а не наша логіка).
* **NestJS**
  * *Плюси:* Вбудований DI-контейнер "з коробки"; ідеальна модульна структура для Enterprise-додатків.
  * *Мінуси:* Занадто "важкий" для поточних потреб; диктує власні архітектурні патерни, що завадить виконати вимогу ручного рефакторингу та винесення модуля.

## Decision
Ми обрали **Fastify** як основний HTTP-фреймворк для нашого бекенду.

## Consequences
* **Позитивні:** Ми отримаємо максимально "чисті" результати під час виконання навантажувальних тестів; Zod-валідація легко інтегрується в життєвий цикл запиту Fastify.
* **Негативні:** Команді доведеться витратити додатковий час на вивчення системи плагінів Fastify; реалізацію Dependency Injection доведеться налаштовувати самостійно (вручну або через сторонні бібліотеки на кшталт Awilix).
