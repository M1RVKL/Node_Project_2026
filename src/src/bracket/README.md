
# Bracket Module

## Призначення

Модуль відповідає за формування та управління турнірними сітками.

## Основні обов'язки

- Формування турнірних сіток.
- Розподіл учасників за посівом (seeding).
- Підтримка формату Single Elimination.
- Підтримка формату Double Elimination.
- Визначення наступних матчів відповідно до результатів попередніх.
- Визначення переможця турнірної сітки.

## Міжмодульна взаємодія

Модуль отримує список зареєстрованих учасників через публічний інтерфейс RegistrationModule.

Для створення та оновлення матчів використовує публічний інтерфейс MatchModule.

Прямий доступ до внутрішньої реалізації інших модулів заборонений.

## Основні сутності

- TournamentBracket
- BracketRound
- BracketPosition

## Основні обмеження

- У турнірній сітці можуть брати участь лише зареєстровані учасники.
- Один учасник не може одночасно займати декілька позицій в одній сітці.
- Перехід між раундами повинен відповідати результатам попередніх матчів.
