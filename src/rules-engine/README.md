
# Rules Engine Module

## Призначення

Модуль відповідає за перевірку та застосування правил настільного тенісу під час проведення матчів.

## Основні обов'язки

- Перевірка коректності рахунку.
- Перевірка умов завершення сету.
- Перевірка умов перемоги в матчі.
- Обробка ситуації з рахунком 10:10.
- Визначення переможця відповідно до правил гри.
- Надання результатів перевірки іншим модулям.

## Міжмодульна взаємодія

MatchModule використовує публічний інтерфейс RulesEngineModule для перевірки результатів матчів.

Модуль не повинен напряму змінювати записи матчів у базі даних.

Він отримує необхідні дані через DTO та повертає результат перевірки через публічний інтерфейс.

## Основні бізнес-правила

- Стандартний сет грається до 11 очок.
- Для перемоги необхідна різниця щонайменше у 2 очки.
- При рахунку 10:10 гра продовжується до досягнення різниці у 2 очки.
- Некоректні значення рахунку повинні відхилятися.
- Переможець визначається лише після виконання умов завершення матчу.

## Основні обмеження

- Модуль не відповідає за збереження результатів.
- Модуль не керує реєстрацією учасників.
- Модуль не формує турнірні сітки.
- Перевірка правил повинна бути незалежною від HTTP-фреймворку та бази даних.

## Статус реалізації

На поточному етапі визначено відповідальність модуля та його бізнес-правила. Реалізація алгоритмів і автоматизовані тести потребують подальшої розробки.
