## 2. Топ-3 виявлені розбіжності та виправлення

### 2.1. Недостатня деталізація специфікації

**Виявлена проблема:**

- Відсутні критерії прийняття (Acceptance Criteria).
- Неузгоджені назви полів: max_players, current_slots, max_slots та maxSlots.
- Недостатньо описані зв'язки між сутностями.
- Не було чіткого зв'язку IdempotencyKeys із конкретним матчем.

**Виконані виправлення:**

- Додано розділ Acceptance Criteria.
- Узгоджено назви полів: max_players та current_players.
- Описано зв'язки між Users, Tournaments, Registrations, Matches та IdempotencyKeys.
- Уточнено зв'язок ключа ідемпотентності з користувачем та матчем.
- Розширено опис транзакційної реєстрації.

**Коміт:** `c4ed7c2`

### 2.2. Недостатня структура архітектурної документації

**Виявлена проблема:**

- В ADR 001 були відсутні окремі розділи Decision Drivers та Considered Options.
- Не вистачало шаблону специфікації.
- Не вистачало шаблону ADR за MADR.

**Виконані виправлення:**

- ADR 001 приведено до структури MADR.
- Додано Decision Drivers.
- Додано Considered Options.
- Створено шаблон специфікації spec-template.md.
- Створено шаблон архітектурного рішення adr-template.md.

**Коміти:**
- `6e0a0c0` — оновлення ADR.
- `c8201ed` — шаблон специфікації.
- `3f2d309` — шаблон ADR.

### 2.3. Невідповідність структури та інженерних стандартів

**Виявлена проблема:**

- У src не було документаційного каркаса чотирьох доменних модулів.
- Definition of Done містив вимоги до інструментів, наявність яких не була підтверджена.
- Makefile викликав npm-скрипти test, build та dev, яких немає в package.json.

**Виконані виправлення:**

- Створено документаційні описи модулів registration, bracket, match та rules-engine.
- Оновлено Definition of Done відповідно до фактичного стану інструментів.
- Зафіксовано невідповідність між Makefile та package.json для подальшого виправлення.

**Коміти:**
- `d349022` — оновлення DoD.
- `1bfe037` — модуль registration.
- `e64c3a0` — модуль bracket.
- `3e11bc7` — модуль match.
- `e8ab8e8` — модуль rules-engine.

**Окремо виявлена неправильна залежність:**

Makefile викликає npm run test, npm run build та npm run dev, але відповідні скрипти відсутні в package.json. Ця проблема задокументована та потребує окремого технічного виправлення.
