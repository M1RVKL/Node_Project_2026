
# Діалог 3. Перевірка Definition of Done та інструментів

## Повідомлення 1

**User:**

Перевір Definition of Done нашого Node.js-проєкту. Порівняй вимоги документа з реальними файлами package.json та Makefile. Знайди інструменти та команди, які згадуються в документації, але відсутні або не налаштовані в репозиторії.

**AI:**

Під час перевірки необхідно звернути увагу на:

1. Наявність npm-скриптів test, build та dev.
2. Відповідність команд Makefile налаштуванням package.json.
3. Наявність Commitlint.
4. Наявність GitHub Actions.
5. Наявність налаштованого тестового середовища.

Необхідно відрізняти фактично налаштовані інструменти від запланованих.

## Повідомлення 2

**User:**

Не потрібно зазначати, що інструменти працюють, якщо вони фактично не налаштовані. Потрібно залишити реальні можливості репозиторію та описати відсутні компоненти.

**AI:**

Рекомендовано розділити документ на:

- Фактично наявні інструменти.
- Перевірки, які вже можна виконувати.
- Перевірки, які потребують додаткового налаштування.
- Вимоги до майбутніх Pull Request.

Також потрібно вказати, що npm-скрипти test, build та dev відсутні, якщо це підтверджується package.json.

## Повідомлення 3

**User:**

Потрібно зробити чекліст перед злиттям Pull Request та узгодити його з реальним станом проєкту.

**AI:**

Рекомендовано включити до чекліста:

1. Перевірку коду через ESLint.
2. Перевірку форматування через Prettier.
3. Перевірку Git Hooks.
4. Перевірку міжмодульних залежностей.
5. Перевірку документації.
6. Перевірку змін перед злиттям.

Перевірки, для яких ще немає інструментів, слід позначити як такі, що потребують налаштування.

## Повідомлення 4

**User:**

Приймаю запропоновані зміни. Потрібно привести DoD у відповідність до фактичного стану репозиторію.

**AI:**

У standards/DoD.md необхідно:

- Оновити вимоги до перевірки коду.
- Додати чекліст Pull Request.
- Уточнити стан npm-скриптів.
- Прибрати непідтверджені твердження про CI та Commitlint.
- Зафіксувати правила оновлення стандартів.

## Результат роботи

У standards/DoD.md уточнено вимоги Definition of Done, додано чекліст перед злиттям та описано фактичний стан інструментів проєкту.
